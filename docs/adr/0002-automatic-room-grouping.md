# ADR-0002: Список групп по помещениям без переключателя

**Статус:** принято, заменяет [ADR-0001](0001-room-grouping-by-default.md)
**Дата:** 13.11.2026

## Контекст

После ADR-0001 группировка по помещениям включалась сама, а кнопка «По помещениям» оставалась, чтобы показать список подряд. Электрик думает помещениями, а порядок номеров как на щитке выравнивает «Номера по порядку». Кнопка добавляет на экран выбор, который почти никто не делает, и второе состояние списка, которое нужно поддерживать и тестировать.

## Решение

1. Кнопки «По помещениям» и настройки `ampli-listby` больше нет. Вид списка определяется только данными проекта.
2. Помещений два и больше (считая «Без помещения»): список по помещениям с заголовками, итогом и сворачиванием. Иначе список подряд без заголовков.
3. Правило по-прежнему в `roomGroups` (`src/core/zonelist.ts`): помещения без учёта регистра, в порядке первой группы, «Без помещения» в конце.
4. «Номера по порядку» показывается, когда номера внутри помещений идут не подряд.
5. Перестановка группы раньше и позже в карточке всегда идёт внутри её помещения, как в списке.
6. После удаления группы клавишей Delete фокус переходит на следующую строку списка по месту на экране, а не по номеру.

## Рассмотренные варианты

| Вариант | Плюсы | Минусы |
| --- | --- | --- |
| А. Оставить кнопку (ADR-0001) | Можно посмотреть список строго по номерам | Лишний элемент в шапке списка, два режима в коде и тестах |
| Б. Автоматически, без кнопки (выбран) | Один вид списка, меньше кода, на телефоне больше места | Посмотреть список по номерам можно только на щитке |
| В. Автоматически, кнопка спрятана в меню | Возможность остаётся | Скрытая настройка, которую никто не найдёт, а код двух режимов остаётся |

## Последствия

- Ключ `ampli-listby` в браузерах пользователей больше не читается и ни на что не влияет.
- Модульные тесты идут по тому же виду списка, что видит электрик; для выбора строки по номеру есть `rowNo` в `src/test/ui/util.tsx`.
- Порядок групп на щитке не меняется: он задаётся номерами, а «Номера по порядку» выравнивает их по помещениям.
- При удалении первой группы помещения само помещение может сместиться в списке, потому что порядок помещений идёт по первой группе.
