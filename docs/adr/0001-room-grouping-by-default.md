# ADR-0001: Список групп по помещениям по умолчанию

**Статус:** заменено [ADR-0002](0002-automatic-room-grouping.md)
**Дата:** 13.11.2026

## Контекст

Список групп можно показать подряд или по помещениям с заголовком, итогом мощности и сворачиванием. Электрик думает помещениями: так собирается проект в «Комнатах», так работает УЗО на помещение и так подписан щиток.

Группировка уже включена по умолчанию (ключ `ampli-listby`, по умолчанию `room`), но работала механически:

- если ни у одной группы нет помещения, весь список уходил под один заголовок «Без помещения»;
- если все группы в одном помещении, был один заголовок над всем списком;
- кнопка «По помещениям» показывалась и там, где ничего не меняла;
- «Кухня» и «кухня» из старого файла давали два заголовка, хотя при загрузке проекта и при вводе помещения регистр приводится к одному.

## Решение

1. Группировка по помещениям остаётся по умолчанию, выбор хранится на устройстве, а не в проекте.
2. Заголовки появляются, только когда помещений хотя бы два, считая «Без помещения». Иначе список идёт подряд, кнопка «По помещениям» и «Номера по порядку» не показываются.
3. Помещения сравниваются без учёта регистра и пробелов по краям, подпись берётся у первой группы.
4. Порядок: помещения в порядке первой группы, «Без помещения» в конце.
5. Правило лежит в чистой функции `roomGroups` в `src/core/zonelist.ts` с модульными тестами; там же константа `NO_ZONE`, которую использует `zoneOf`.

## Рассмотренные варианты

### А. Хранить выбор в проекте

| Критерий | Оценка |
| --- | --- |
| Сложность | средняя: поле в `Project`, шаг миграции, фикстура `full.ts` |
| Влияние | вид списка попадает в ссылки `#p=` и файлы |

Отклонён: это предпочтение вида, а не данные объекта. Клиент, открывший ссылку, не должен получать чужой вид списка.

### Б. Хранить на устройстве (выбран)

Так уже устроено, миграция не нужна. Если электрик когда-то выключил группировку, выбор сохраняется: значение `no` не сбрасываем.

### В. Группировать всегда, без переключателя

Отклонён: при перестановке групп на щитке удобен общий список в порядке номеров.

## Последствия

- Новый проект, набранный вручную без помещений, выглядит как простой список; заголовки появляются, когда у групп появляются разные помещения.
- Новая группа без помещения в проекте с помещениями встаёт в «Без помещения» внизу списка. Подставлять помещение выбранной группы не стали: при УЗО на помещение это молча меняет щиток.
- Модульные тесты по-прежнему запускаются с выключенной группировкой (`src/test/setup.ts`), поведение по умолчанию проверяет `src/test/ui/rooms-list.test.tsx`.
