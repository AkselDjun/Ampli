# Дизайн-система Ampli

Все значения оформления живут в `src/styles/tokens.css`. Правила компонентов лежат в файлах по экранам и ссылаются на токены через `var(--…)`. Голые цвета, именованные цвета и числовые `z-index` в стилях компонентов запрещены: это проверяют Stylelint (`npm run lint`) и тест `src/test/design/tokens.test.ts`.

## Файлы и слои

`src/styles/app.css` только собирает файлы через `@import` и задаёт порядок слоёв `@layer tokens, base, components`. Слой с более поздним именем побеждает раньше объявленный независимо от специфичности, поэтому сброс и типографика из `base` никогда не перебьют правила компонентов.

| Файл | Слой | Что внутри |
| --- | --- | --- |
| `media.css` | | именованные брейкпоинты `@custom-media`, в сборку не попадает |
| `tokens.css` | `tokens` | токены и обе темы |
| `base.css` | `base` | шрифты, сброс, заголовки, `.lbl`, `.muted`, `.mono`, `.sr` |
| `kit.css` | `components` | кнопки, поля, `Seg`, `Stepper`, чипы, подсказки, вкладки, тосты |
| `layout.css` | `components` | рабочая область, колонки, нижние вкладки на телефоне, карточки |
| `appbar.css` | `components` | шапка, табло итогов и его всплывающее окно |
| `group-list.css` | `components` | список групп, строки, автоматы на строке, меню добавления, стартовый экран |
| `editor.css` | `components` | карточка группы, приборы, замеры и фото, свёрнутые блоки |
| `panel.css` | `components` | щиток, DIN-рейка, замеры на щитке, проверки, фазы |
| `sheets.css` | `components` | окна, таблицы, отчёт, проекты, смета, палитра команд |
| `print.css` | `components` | печать; подключается отдельным `<link media="print">` из `main.tsx` и не грузится в основной CSS |
| `onboarding.css` | `components` | обучение, ленивый чанк |

Внутри слоя `components` порядок файлов важен: при равной специфичности побеждает правило из файла ниже по списку. Новое правило кладите в файл своего экрана; если оно переопределяет правило из другого файла, проверьте, что его файл стоит ниже.

## Брейкпоинты

Ширины экранов задаются только именами из `media.css`: `@media (--tablet){…}`. Lightning CSS при сборке подставляет вместо имени сам запрос.

| Имя | Запрос | Назначение |
| --- | --- | --- |
| `--phone` | до 560 px | телефон |
| `--tablet` | до 760 px | телефон и узкий планшет: крупные поля, окна снизу |
| `--above-tablet` | от 761 px | дополнение к `--tablet` |
| `--narrow` | до 999 px | одна колонка и нижние вкладки |
| `--desktop` | от 1000 px | две колонки |
| `--wide`, `--wide-l`, `--wide-xl` | от 1200, 1300, 1600 px | три колонки и шире |
| `--upto-359` … `--upto-640` | до 359, 380, 420, 440, 480, 520, 600, 639, 640 px | точечные правки узких экранов, кандидаты на слияние с `--phone` |

## Темы

Светлая тема задана в `:root`. Тёмная включается по системной настройке (`prefers-color-scheme: dark`) или принудительно атрибутом `data-theme="dark"` на `<html>`; `data-theme="light"` принудительно включает светлую. Блоки тёмной темы для системной и принудительной настройки должны совпадать, тест падает при расхождении. В тёмной теме переопределяются только токены, у компонентов своих правил под тёмную тему нет.

## Правила

- Новый цвет сначала добавьте в `tokens.css` с осмысленным именем и значением для тёмной темы, если он должен меняться.
- Отступы берите из шкалы `--s-*`. Значения вне шкалы (10, 14, 3, 5, 22 px) остались в старых правилах и будут сведены к шкале постепенно.
- Чертёж А3 и значки жил в `Icons.tsx` рисуются фиксированными цветами по ГОСТ и цветовой маркировке проводов, это не токены темы.

## Компоненты

Общие компоненты лежат в `src/ui/kit.tsx`, интерактивные блоки с поведением (`Seg`, `Stepper`, `ArmButton`, `Tabs`, `Sheet`, `Fold`, `Tip`) в `src/ui/common.tsx`.

| Компонент | Когда использовать |
| --- | --- |
| `Button` | любая кнопка с текстом. `variant`: `default`, `primary` (одно главное действие на экране), `ghost` (второстепенное), `danger` (удаление); `size="sm"` для плотных строк. По умолчанию `type="button"` |
| `IconButton` | кнопка только со значком. `label` обязателен и становится `aria-label`, `tip` показывает подсказку при наведении |
| `Field` | подпись, поле ввода и подсказка под ним. `id` связывает подпись с полем, `wide` растягивает на всю строку сетки |
| `ArmButton` | необратимое действие в два нажатия: первое взводит, второе выполняет. Принимает те же `variant` и `size`, `link` делает его ссылкой |

Вместо `<button className="btn …">` используйте `Button`, вместо `<button className="icon-btn" aria-label=…>` используйте `IconButton`.

## Подсказки

На телефоне нет наведения, поэтому пояснения делятся на три уровня.

| Уровень | Как | Для чего |
| --- | --- | --- |
| Подпись под полем | `<small className="muted">` или `hint` у `Field`, видна всегда | понятие, без которого поле нельзя заполнить правильно. Одна строка, до 60 знаков |
| Кружок «i» | `Tip`, открывается нажатием | зачем это нужно и по какой норме. До 200 знаков и трёх предложений |
| Наведение | `data-tip` или `tip` у `IconButton` | только повтор подписи значка на компьютере, например горячая клавиша |

- Первая фраза отвечает «что это и что ввести», ссылка на норму в конце в скобках
- Всё длиннее трёх предложений уходит в «Как посчитано» или в отчёт
- Если в тексте есть «квартира», для режима «Частный дом» он говорит «дом»
- На телефоне не упоминать клавиши
- Элемент с `data-tip` должен иметь видимый текст или `aria-label`, это проверяет `src/test/ui/hover-hints.test.tsx`

## Шрифт

Ampli Sans собран из IBM Plex Sans (SIL OFL 1.1, текст лицензии в `src/styles/ampli-sans-OFL.txt`). Имя «Plex» зарезервировано лицензией, поэтому урезанная версия называется по-своему. Один файл `src/styles/ampli-sans-wght.woff2`, около 42 kB: вес 400–700, латиница, русская и белорусская кириллица, `№`, `²`, `×`, `Δ`, `φ`, `Ω`, `ρ`, `Σ`, `√`, `≤`, `≥`, стрелки и типографские знаки. Файл подгружается заранее через `preload` и хранится в кэше PWA. Пока он грузится, текст показывается системным шрифтом с подогнанными метриками (`Ampli Sans Fallback`), чтобы строки не прыгали. Новый символ в интерфейсе нужно добавить в набор при пересборке файла, иначе e2e-тест `fonts.spec.ts` упадёт. Бюджет шрифтов 48 kB проверяет `npm run size`.
