# Дизайн-система Ampli

Все значения оформления живут в `src/styles/tokens.css`. В `src/styles/app.css` только правила компонентов, они ссылаются на токены через `var(--…)`. Голые цвета, именованные цвета и числовые `z-index` в `app.css` запрещены: это проверяют Stylelint (`npm run lint`) и тест `src/test/design/tokens.test.ts`.

## Темы

Светлая тема задана в `:root`. Тёмная включается по системной настройке (`prefers-color-scheme: dark`) или принудительно атрибутом `data-theme="dark"` на `<html>`; `data-theme="light"` принудительно включает светлую. Блоки тёмной темы для системной и принудительной настройки должны совпадать, тест падает при расхождении. В тёмной теме переопределяются только токены, у компонентов своих правил под тёмную тему нет.

## Правила

- Новый цвет сначала добавьте в `tokens.css` с осмысленным именем и значением для тёмной темы, если он должен меняться.
- Отступы берите из шкалы `--s-*`. Значения вне шкалы (10, 14, 3, 5, 22 px) остались в старых правилах и будут сведены к шкале постепенно.
- Чертёж А3 и значки жил в `Icons.tsx` рисуются фиксированными цветами по ГОСТ и цветовой маркировке проводов, это не токены темы.

## Компоненты

Общие компоненты лежат в `src/ui/kit.tsx`, интерактивные блоки с поведением (`Seg`, `Stepper`, `ArmButton`, `Tabs`, `Sheet`, `Fold`, `Tip`) в `src/ui/common.tsx`.

| Компонент | Когда использовать |
| --- | --- |
| `Button` | любая кнопка с текстом. `variant`: `default`, `primary` (одно главное действие на экране), `ghost` (второстепенное), `danger` (удаление); `size="sm"` для плотных строк. По умолчанию `type="button"` |
| `IconButton` | кнопка только со значком. `label` обязателен и становится `aria-label`, `tip` показывает подсказку при наведении |
| `Field` | подпись, поле ввода и подсказка под ним. `id` связывает подпись с полем, `wide` растягивает на всю строку сетки |
| `ArmButton` | необратимое действие в два нажатия: первое взводит, второе выполняет. Принимает те же `variant` и `size`, `link` делает его ссылкой |

Вместо `<button className="btn …">` используйте `Button`, вместо `<button className="icon-btn" aria-label=…>` используйте `IconButton`.
